## GitHub release body

```markdown
# STAMPEDE v0.2.0 — Milestone 2

**Secured end-to-end product — browser-to-database checkout journey with
OAuth2.1 PKCE auth, API gateway, rate limiting, Stripe payments, email
notifications, and Playwright E2E tests. Built on the zero-oversell core
from v0.1.0.**

## What's new in v0.2.0

### Identity & Auth (STAM-identity)
- **OAuth2.1 Authorization Server** with PKCE (Authorization Code +
  S256 challenge). Client: `stampede-spa`, public client.
- **Rotating refresh tokens** with reuse detection — replayed tokens
  trigger family revocation.
- **RBAC** with `USER` and `ORGANIZER` roles enforced via
  `@PreAuthorize`. BOLA protection on user-scoped endpoints.
- **Audit events** published to `identity.audit` Kafka topic.

### API Gateway (STAM-gateway)
- **Spring Cloud Gateway** routing all traffic to backend services.
- **JWT validation** via identity-service JWKS endpoint — services
  behind gateway no longer validate tokens individually.
- **Correlation ID minting** — every request gets a trace header
  carried through Kafka consumers.
- **Redis token-bucket rate limiting** — booking: 10 req/s burst 20
  per user; identity: 5 req/s burst 10 per IP.

### Payments (STAM-payment)
- **Stripe test mode** replaces the mock PSP from v0.1.0.
  PaymentIntents, webhooks, and idempotency keys.

### Notifications (STAM-notification)
- **Email notifications** for booking confirmation and cancellation.
- Idempotent Kafka consumer; Mailhog for local delivery.

### Frontend (STAM-frontend)
- **React + Vite + TypeScript SPA** with Tailwind 4.
- **Seat-map grid** with live availability polling, 409 conflict
  handling, and 429 rate-limit UX.
- **Checkout flow** with hold countdown (5-minute timer, threshold
  styling at 60s/30s/10s), Stripe Elements, and payment outcome states.
- **PKCE auth integration** — tokens in memory, refresh via httpOnly
  cookie, silent 401 interceptor with request deduplication.

### Testing
- **38 Playwright E2E tests** across 5 spec files: happy-path checkout
  journey, seat-taken race (two browser contexts), hold expiry,
  RBAC negative, rate-limit UX.
- **Page-object pattern** with global auth fixture.
- **Nightly CI workflow** running full E2E suite; traces/videos/
  screenshots uploaded as artifacts on failure.

### Infrastructure
- **Eureka + Config Server** for service discovery and centralized
  config (temporary — Sprint 3 replaces with K8s DNS per ADR-0004).
- **Dev-only test seed endpoint** in catalog for predictable E2E data.

## Reproducing

```bash
git clone https://github.com/stampede-io/STAM-platform
cd STAM-platform
bash scripts/clone-all.sh
cd compose-dev
cp .env.example .env
docker compose up -d --build --wait

# Run secured flash-sale load test
bash ../load-tests/k6/run-flash-sale-secured.sh

# Run Playwright E2E (from STAM-frontend)
cd ../../STAM-frontend
npm ci && npx playwright install --with-deps chromium
npx playwright test
```
